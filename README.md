# Moaaz.Dev

Personal portfolio of **Moaaz Eldeep** — a fourth-year Artificial Intelligence student at Zagazig University.

**Brand:** Moaaz.Dev  
**Message:** Building Intelligent Solutions with AI, Machine Learning & Data

## Stack

Static site only:

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or animation libraries.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Project structure

```text
index.html
css/style.css
js/script.js
assets/
  images/
    profile.png
    logo.png
    favicon.png
    certifications/
    project-covid.jpg   (optional)
  cv/
    Moaaz-Eldeep-CV.pdf  (optional)
```

## Assets to add

- Place the CV at `assets/cv/Moaaz-Eldeep-CV.pdf` so **Download CV** works.
- Optional project cover: `assets/images/project-covid.jpg`. If it is missing, a clean placeholder is shown.
